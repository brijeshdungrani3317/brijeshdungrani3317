## ◈ How I Think

*This is what separates good engineers from great ones.*

**I start with the outcome, not the tool.**
Before I write a single line of code or pick a model, I ask: *What decision does this data need to enable? What behavior does this AI need to change?*

**I treat AI like a product, not a prototype.**
Anyone can demo a chatbot. I build things that are reliable at 2am when no one is watching, handle edge cases, and don't hallucinate in front of your CEO.

**I obsess over AGI.**
Not because it's trending — because understanding where intelligence is going shapes every architectural decision I make today. I follow frontier research and translate it into practical tools.

**I think in systems, not features.**
A dashboard is not a solution. An agent that monitors, alerts, explains, and recommends — that's a system. I build systems.
